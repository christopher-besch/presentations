General Implementation Approach

  • Strong, simple, fix interfaces
    • Independent development
    • Free to optimize implementation
  • Tests, tests, tests!!!
    • Rapid iteration
  • debug_asserts invariances
    • Bugs easier to find
  • No unsafe
  • Focus on general optimizations (not edge cases)
  • No hardware-specific optimizations

  • Great interfaces are great

    • Rust has great tooling
